# 举棋不定（Chess Melee）Demo

**当前公开版本：v0.1.7**

《举棋不定》是一款 9×9 双人回合制策略游戏。当前公开版本只开放“落子争锋”：棋盘上的棋子不能移动，玩家每回合从棋篮取出当前棋子并落到空格；连线、特殊棋攻击、墓地回收与灵魂计分都围绕这一次落点结算。

游戏借用中国象棋与国际象棋中容易辨认的棋型，但不以“将军、将死”决定胜负。真正争夺的是落点、攻击轨迹、特殊棋资源和无法清除的灵魂地形。

## 回合与落子流程

1. 蓝方先手，双方交替行动。
2. 每个正常回合必须把当前可用棋子落到一个空格，不能移动盘上的棋子，也不能主动跳过回合。
3. 棋篮中有可取出的特殊棋时，必须优先使用队首特殊棋；没有可用特殊棋时才取基础棋。
4. 己方将／帅不在场时，士／仕不参与三连随机，也暂时不能取出。旧对局或教学预置中已经存在的士／仕会留在原有顺序，系统继续寻找后面的可用特殊棋，避免卡住棋篮。
5. 提起棋子后，棋盘会预览该落点的完整攻击轨迹与可吃目标；右键可以取消尚未提交的落子。
6. 落子提交后，先锁定并结算特殊棋攻击，再按照本次落点检查横、竖与两条斜线。
7. 三连奖励进入棋篮，四连进入全局淘汰阶段，五连生成灵魂；全部待处理效果完成后才切换回合。

普通回合超时时，系统会从合法空格中自动完成当前必须使用棋子的落子。如果已经没有合法落点，则安全进入终局判断。

## 连线规则

系统只检查经过本次落点的四个方向：横向、纵向、左上至右下、右上至左下。

- 棋子必须连续相邻、属于同一阵营，中间不能有空格。
- 灵魂不参与连线，并会中断连线。
- 基础棋与特殊棋可以混合组成三连、四连和五连。
- 二连只允许两枚基础棋组成，特殊棋落子不会触发二连。
- 每个方向按照该方向完整连续线的长度结算一次，不把一条长线拆成多个短线重复领奖。
- 不同方向独立判定。同一次落子可以同时触发二连、三连、四连或五连中的多种效果。
- 同一方向达到五连及以上时只结算飞升，不再领取该方向的三连或四连奖励。

### 二连：落子挤压

基础棋落下并在某个方向形成恰好二连时，检查连线两端紧邻的敌方非灵魂棋。

- 目标正后方紧邻一枚同阵营非灵魂棋时，目标受到保护并保留。
- 目标后方为空、越界、是另一阵营棋或是灵魂时，目标没有保护并被淘汰。
- 棋盘边缘视为无保护。
- 灵魂不能成为目标，也不能保护其他棋。
- 两端和多个方向分别检查；所有目标基于同一落子后的棋盘快照锁定，再同时删除，不产生连锁吃子。
- 被挤掉的基础棋直接离场，特殊棋进入其所属阵营墓地。

### 三连：特殊棋入篮

- 每个恰好三连的方向分别获得一枚随机特殊棋。
- 多个方向同时三连会获得多枚棋，按横、纵、两条斜线的固定顺序加入棋篮尾部。
- 奖励不会在当前回合立即攻击，要等到之后轮到它成为队首时再落下。
- 抽取会消耗对应棋型的有限供应；库存为 0 的棋型不再参与抽取。
- 己方将／帅尚未在场时，士／仕不会进入本次随机候选池；将／帅上场后才恢复抽取资格。
- 随机状态是确定性的，同一初始状态与行动序列会得到相同结果，供本地规则、AI、回放和联机共同使用。

### 四连：自动回收＋保留淘汰

每个恰好四连的方向都会独立执行以下效果：

1. 当前回合增加 15 秒。
2. 自动把己方墓地中最近阵亡的一枚特殊棋移回对应的类型供应库存，不插入棋篮；墓地为空时跳过回收。
3. 保留一次全局淘汰权，玩家必须选择场上任意一枚敌方或己方非灵魂棋。

全局淘汰可以选择基础棋或特殊棋，但不能选择灵魂。多个方向同时形成四连时，需要逐次完成每一次淘汰；若场上只剩灵魂，没有合法目标，剩余权利会被安全清除。

自动回收完成时墓地会立即刷新；该棋之后需要通过新的三连奖励，才有机会再次被抽进棋篮。

### 五连及以上：灵魂飞升

- 连线中的基础棋全部转化为灵魂，每枚记 1 分。
- 特殊棋可以连接五连，但保持原棋型，不会飞升。
- 多方向五连分别结算；交点上的同一枚基础棋只计分一次。
- 五连不会立即结束对局，仍按正式终局条件判断胜负。

## 特殊棋落地攻击

特殊棋落下前，预览与实际结算使用同一套攻击投影：

1. 根据预定落点计算完整攻击轨迹。
2. 只把敌方非灵魂棋标记为可吃目标；空格、己方棋与灵魂不会被攻击。
3. 提交落子时锁定预览中的目标快照。
4. 落地后同时淘汰全部锁定目标，不会因为先删除某枚棋而重新计算路线。
5. 攻击完成后，特殊棋留在落点，可以参与之后的三连、四连与五连，但不能移动，也不能触发二连。

## 棋子规则与数量

| 棋型 | 每方上限 | 落地攻击 |
| --- | ---: | --- |
| 将／帅 | 1 | 双向延长的“仕线” |
| 士／仕 | 2 | 朝向己方将／帅的三向一格 |
| 象／相 | 2 | 四个斜向两格，受象眼阻挡 |
| 车 | 2 | 横竖四条直线，遇到首枚棋停止 |
| 马 | 2 | 日字目标，受马脚阻挡 |
| 炮 | 2 | 直线上越过恰好一个炮架后攻击首枚敌棋 |
| 卒／兵 | 5 | 己方前进方向的两个斜前方一格 |
| 皇／后 | 1 | 四条斜线，遇到首枚棋停止 |

每方特殊棋类型容量共 17 枚。

### 将／帅：双向延长仕线

以落点朝己方前进方向一格的位置作为两条“仕线”的交点，再沿穿过交点的两条完整斜线向四端双向延伸。交点与每个分支遇到第一枚棋时停止；首枚棋是敌方非灵魂棋时将其吃掉。将／帅被吃不会直接输掉对局，而是进入己方墓地。

### 士／仕：向王三向

士／仕只有在己方将／帅已经在场时才会被三连随机获得或从棋篮取出。落地时以己方将／帅所在方向为中心，攻击朝向王的一格以及左右相邻两个方向的一格，共三个目标。

### 象／相

攻击四个斜向两格的终点。中间一格是象眼，象眼被任何棋占据时，该方向失效；没有传统象棋的过河限制。

### 车

沿横向和纵向四个方向延伸。每个方向遇到第一枚棋时停止；首枚棋是敌方非灵魂棋时将其吃掉，不能越过阻挡继续攻击。

### 马

攻击日字终点。每个轴向对应一个紧邻的马脚；马脚被任何棋占据时，该轴向对应的两个马步都失效。

### 炮

每个横竖方向必须先越过恰好一枚棋作为炮架，再攻击炮架之后遇到的第一枚敌方非灵魂棋。己方棋、敌方棋和灵魂都可以成为炮架；遇到目标后不能继续攻击更远棋子。

### 卒／兵

只攻击己方前进方向的两个斜前方一格，不攻击正前方或横向。

### 皇／后

只沿左上、右上、左下、右下四条斜线攻击，不包含横线和竖线。每个方向遇到第一枚棋时停止；首枚棋是敌方非灵魂棋时将其吃掉。

## 棋篮、供应池与墓地

每个阵营同时维护三类资源：

- **棋篮**：已经通过三连获得、等待按先进先出顺序落下的特殊棋；
- **类型供应池**：每种特殊棋还剩多少枚可以被之后的三连抽到；
- **墓地**：已经阵亡、等待四连自动回收的特殊棋，最近阵亡者优先。

三连抽中某种棋时，该类型供应减少 1。特殊棋进入棋盘后不会自动回到供应池；无论被二连、特殊棋攻击、四连或其他合法方式淘汰，都会进入所属阵营墓地。四连会把最近阵亡的特殊棋恢复到对应类型供应库存，不进入棋篮，同时仍保留全局淘汰。

基础棋被淘汰后直接离场，不进入墓地。灵魂不能死亡，也不会进入棋篮或墓地。

## 灵魂、计分与终局

### 灵魂性质

- 每枚灵魂记 1 分并永久占据当前格。
- 灵魂不能移动、攻击、被吃或被四连淘汰。
- 灵魂不参与之后的二、三、四、五连，并会中断连线。
- 灵魂不能保护其他棋免受二连挤压。
- 灵魂会阻挡直线攻击、象眼与马脚，也可以作为炮架。

### 终局条件

对局会在以下情况进入结算：

1. 任意一方基础棋供应为 0，且棋篮中没有当前可取出的特殊棋；仅剩因将／帅缺席而锁定的士／仕不会让对局无限卡住。
2. 棋盘填满，没有任何空格。
3. 一方灵魂领先已经超过另一方理论上还能追赶的最大值。
4. 玩家认输。
5. 联机断线方未在权威恢复宽限结束前返回。

如果最后一枚基础棋形成三连并获得特殊棋，奖励会正常进入棋篮，对局继续。

正式比较顺序为：先比较灵魂数量，再比较场上普通非灵魂棋数量；两项都相同则判为平局。

## 计时、悔棋与认输

- 每个回合从 60 秒开始计时。
- 每条四连为当前阶段增加 15 秒。
- 倒计时到 0 秒时先显示 0，并保留 2 秒结算宽限，再执行超时自动落子或安全终局。
- 认输会立即结束本局；认输按钮不会触发悔棋或冻结界面。
- 悔棋只在本地 AI 对战开放，可以连续回退，直到返回开局。
- 每次悔棋会恢复棋盘、棋篮、库存、墓地、随机状态、AI 记忆和回合归属，并把当前回合时间重置为 60 秒。
- 悔棋按钮只显示“悔棋”，不显示剩余次数；也可使用 `Ctrl+Z`。

## AI、联机与教程

### 本地 AI

- 简单与困难 AI 使用同一套规则，没有隐藏信息、额外棋子或非法行动权限。
- AI 会评估多方向连线、特殊棋攻击、有限库存、墓地回收和四连主动淘汰己方棋的战术价值。
- 搜索会惩罚近期重复局面与反复落在同一区域的行为。

### 本地双人与在线匹配

- 本地双人使用同一设备轮流操作。
- 在线双方使用相同的 9×9“落子争锋”规则和权威状态。
- 落子、攻击目标、库存、墓地、随机状态、计时与四连阶段通过版本和哈希校验同步。
- 对手的上一步落点提示双方都可见。
- 瞬时掉线不会直接判负；断线恢复、完整快照与房主迁移会继续维护当前对局。

### 新手教程

教程与正式对局复用相同的落子攻击投影，固定使用 9×9“落子争锋”。教程依次覆盖：

- 基础落子与取消操作；
- 二连的保护、边缘和双端挤压；
- 三连召子与棋篮顺序；
- 所有特殊棋的完整攻击轨迹；
- 王与仕的组合规则；
- 四连自动回收、全局淘汰和隐藏技巧；
- 五连飞升、灵魂计分与终局；
- 敌方行动和连续完整实战。
