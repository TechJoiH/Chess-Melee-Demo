# 举棋不定（Chess Melee）Demo

《举棋不定》是一款将自由落子、棋子移动、连线组合、空间挤压与灵魂计分融合在同一张棋盘上的双人回合制策略游戏。

游戏借用了中国象棋与国际象棋中容易辨认的棋子与移动方式，但不使用“将军、将死”决定胜负。玩家真正争夺的是棋盘空间、特殊棋资源、连线带来的战术权利，以及五连生成的灵魂分数。

> 本仓库只提供可玩 Demo 与公开玩法说明。Unity 项目和游戏源代码保存在私有仓库中，不随 Demo 发布。

## 游戏目标与基本流程

### 阵营与先后手

- 游戏分为蓝方与红方，蓝方固定先手。
- 正式对局中双方交替行动。
- 棋子被吃不等于立即输掉对局，将或帅被吃也不会直接结束游戏。

### 难度、棋盘与回合时间

难度会同时改变棋盘规模、每方基础棋供应、回合时间和 AI 搜索强度。

| 难度 | 棋盘 | 每方基础棋供应 | 每回合时间 | AI 强度 |
| --- | --- | ---: | ---: | --- |
| 简单 | 9×9 | 81 枚 | 60 秒 | 搜索较浅，候选行动较少 |
| 中等 | 14×14 | 196 枚 | 90 秒 | 搜索深度与候选规模居中 |
| 困难 | 19×19 | 361 枚 | 120 秒 | 搜索更深，推演范围更大 |

### 棋篮与落子顺序

每个阵营拥有基础棋供应和一个可以积累特殊棋的棋篮。

1. 三连奖励得到的特殊棋按照获得顺序进入棋篮尾部。
2. 棋篮中存在当前可取出的特殊棋时，必须优先使用最早可用的那一枚，不能改下基础棋。落子争锋中，己方将／帅不在场时士／仕会暂时锁定并被跳过，避免阻塞后续棋子。
3. 特殊棋全部使用完以后，才会继续从基础棋供应中取棋。
4. 正常落子和四连复活落子都只能选择空格。

## 两种规则模式

| 规则 | 标准模式 | 落子争锋 |
| --- | --- | --- |
| 正常回合 | 可以落子、移动己方非灵魂棋或主动结束回合 | 必须落下一枚当前可用棋子，不能移动、不能主动结束回合 |
| 二连 | 只有基础棋主动移动形成二连时才可能挤压 | 基础棋落下形成二连时立即挤压 |
| 特殊棋攻击 | 在棋盘上按照棋型移动，并在合法终点直接吃子 | 从棋篮落下时按照棋型攻击范围同时吃掉所有标记目标，之后留在棋盘且不能移动 |
| 三连 | 每个有效方向获得一枚特殊棋 | 每个有效方向获得一枚特殊棋，等待下一次己方回合按棋篮顺序落下 |
| 四连 | 每次选择“全局淘汰一枚敌棋”或“复活／补充一枚己方棋” | 自动把最近阵亡的一枚己方特殊棋移回棋篮，同时保留一次可选择敌方或己方非灵魂棋的全局淘汰 |
| 特殊棋死亡 | 进入所属阵营墓地，等待四连复活 | 进入所属阵营墓地，等待之后的四连自动回收 |
| 五连 | 连线中的基础棋飞升，特殊棋保留 | 与标准模式相同 |

教程固定使用标准模式。人机、同屏双人和在线匹配均可选择标准模式或落子争锋；在线玩家只会与相同规则模式的对手匹配。

## 双方共有的连线基础

### 连线方向

系统会检查经过本次行动落点的四个方向：

- 横向；
- 纵向；
- 左上至右下的斜线；
- 右上至左下的斜线。

### 连线成立条件

- 棋子必须连续相邻，中间不能有空格。
- 棋子必须属于同一阵营。
- 连线必须经过本次落子、移动或四连复活后的行动位置。
- 灵魂不参与普通连线，并会中断连线。
- 基础棋与特殊棋可以混合组成三连、四连和五连。
- 二连另有更严格条件，详见两种模式各自的二连章节。

### 同方向与多方向

- 每个方向按照该方向完整连续线的实际长度确定一个档位。
- 同一方向恰好三连只获得一次三连奖励，不会把其中多个三格片段重复计算。
- 同一方向形成五连及以上时只结算飞升，不再领取同一条线中的三连、四连奖励。
- 不同方向独立确定档位，一个方向的长连不会取消另一个方向的短连。
- 同一次行动可以同时触发二连、三连、四连或五连中的多个效果。

典型的多方向结算如下：

| 一次行动形成的局面 | 结算结果 |
| --- | --- |
| 横向四连、纵向三连 | 获得一次四连权利和一枚三连特殊棋 |
| 横向四连、斜向有效二连 | 四连与二连分别结算 |
| 横向、纵向同时四连 | 获得两次四连权利，必须逐次处理 |
| 横向、斜向同时三连 | 分别获得一枚特殊棋，按确定顺序进入棋篮 |
| 一个方向形成五连 | 该方向的基础棋飞升，不领取同线三连或四连奖励 |
| 两个方向同时形成五连 | 两条线都结算；交点基础棋只飞升并计分一次 |

## 标准模式完整规则

标准模式同时保留落子、移动、直接吃子、移动二连、墓地和四连复活，是操作与资源循环更完整的规则模式。

### 1. 标准回合可以做什么

在普通回合中，当前玩家可以选择一种行动：

- 从棋篮向任意空格落下一枚当前必须使用的棋子；
- 移动一枚己方场上的非灵魂棋；
- 主动结束回合；
- 认输。

基础棋移动只能前往空格，不能直接移动到敌棋所在格。特殊棋可以按照各自移动规则进入敌方非灵魂棋所在格并直接吃掉目标。

一次落子或移动完成后，系统先完成直接吃子，再检查行动落点经过的四个连线方向。若产生四连，回合会停留在四连选择阶段；所有选择处理完毕后才检查胜负并切换回合。

### 2. 标准模式二连：基础棋移动挤压

#### 必须同时满足的触发条件

- 本次行动是移动，不是从棋篮落子，也不是四连复活落子。
- 行动棋是基础棋。
- 该方向的完整连续线长度恰好为 2。
- 二连中的两枚棋都是同阵营基础棋。
- 二连经过基础棋移动后的落点。
- 二连至少有一端存在符合条件的敌方目标；如果没有实际淘汰目标，不显示二连淘汰效果。

以下情况不会触发标准模式二连挤压：

- 落子形成二连；
- 四连复活落子形成二连；
- 特殊棋移动形成二连；
- 二连中包含特殊棋；
- 该方向实际已经形成三连或更长连线；
- 连线中包含灵魂。

#### 二连两端如何检查

系统沿二连所在直线分别检查两端。每一端只检查紧邻二连的第一格：

| 紧邻二连的格子与目标后方 | 结果 |
| --- | --- |
| 紧邻格为空、越界或是己方棋 | 该端没有目标，不产生淘汰 |
| 紧邻格是敌方灵魂 | 灵魂免疫，不能被淘汰 |
| 紧邻格是敌方基础棋或特殊棋，目标后方为空 | 目标没有保护，被淘汰 |
| 目标位于棋盘边缘，后方越界 | 视为没有保护，目标被淘汰 |
| 目标后方是同阵营基础棋 | 普通同伴提供保护，目标保留 |
| 目标后方是同阵营特殊棋 | 特殊棋同样能提供保护，目标保留 |
| 目标后方是同阵营灵魂 | 灵魂不能提供保护，目标仍被淘汰 |
| 目标后方是另一阵营棋 | 不属于目标的同伴，目标仍被淘汰 |
| 两端都有无保护敌棋 | 两端独立检查，两枚敌棋都可以被淘汰 |

保护只来自目标正后方紧邻的一枚同阵营、非灵魂棋；更远处的同伴不能隔空保护。

#### 多方向二连与结算差异

如果同一次基础棋移动在多个方向形成恰好二连，各方向分别检查。标准模式二连保留自己的移动结算方式，不采用落子争锋的“落子前统一目标快照”：系统按照纵向、横向、左上至右下斜线、右上至左下斜线的顺序处理有效二连；较早方向已经造成的淘汰会成为后续方向判断保护关系时的当前盘面。

#### 被二连淘汰后的去向

- 基础棋直接离场，不进入墓地。
- 特殊棋进入其所属阵营的墓地。
- 灵魂不能成为二连目标。

### 3. 标准模式三连：召唤特殊棋

当某个方向的完整连续线长度恰好为 3 时，该方向获得一枚随机特殊棋。

- 正常落子、棋子移动和四连复活落子都能触发三连。
- 基础棋和特殊棋可以混合组成三连。
- 灵魂不能参与三连。
- 多个方向同时形成三连时，每个方向分别抽取一枚特殊棋。
- 奖励不会立即出现在棋盘，而是追加到棋篮尾部。
- 正常落子时必须按照棋篮的先进先出顺序使用特殊棋。
- 每种棋的抽取概率由该类型剩余数量决定；库存越多，被抽中的权重越高。
- 已耗尽的类型不再参与抽取；所有类型都耗尽时，三连仍成立，但不会生成超出上限的棋子。

抽取由本局的确定性随机状态控制，因此同样的初始状态和行动序列会得到相同结果，确保本地规则、AI 推演、回放和联机权威状态一致。

### 4. 标准模式四连：全局抉择

当某个方向的完整连续线长度恰好为 4 时，玩家获得一次四连选择权。多个方向同时形成四连时，每个方向各提供一次选择。

进入四连选择阶段后：

- 回合不会切换；
- 不会提前执行正常终局比较；
- 不能继续普通落子、移动或主动结束回合；
- 必须处理完所有四连选择权。

每次选择可以执行以下一种效果。

#### 全局淘汰

- 无视距离、阻挡和棋子移动规则，选择棋盘上任意一枚敌方非灵魂棋。
- 可以淘汰敌方基础棋或特殊棋。
- 不能选择己方棋，也不能选择灵魂。
- 被淘汰的敌方基础棋直接离场；特殊棋进入敌方墓地。

#### 复活或补充

系统严格按照以下优先级提供一枚己方棋：

1. 墓地中最近阵亡的特殊棋；
2. 棋篮中最早获得、尚未使用的特殊棋；
3. 一枚基础棋。

玩家只能选择这枚当前候选棋的落点，不能越过墓地改用棋篮，也不能越过棋篮改用基础棋。墓地采用后进先出，棋篮采用先进先出。

复活或补充必须落在空格。该落子仍会检查三连、四连和五连；如果又形成四连，会继续增加待处理的四连选择权。复活落子不是基础棋主动移动，因此不会触发标准模式二连挤压。

### 5. 标准模式五连及以上：灵魂飞升

当某个方向的完整连续线达到 5 枚或更多同阵营非灵魂棋时，触发飞升：

- 连线中的基础棋全部转化为灵魂；
- 连线中的特殊棋保留原状，不会飞升；
- 同时形成多条五连及以上连线时，各方向分别结算；
- 同一枚基础棋位于多条线的交点时只会保持一个灵魂状态，只计 1 分；
- 五连不保证得到 5 分，例如四枚基础棋与一枚皇组成五连时，只会生成 4 枚灵魂；
- 飞升不会立即宣告胜利，之后仍要按照正式终局条件判断。

### 6. 标准模式死亡、墓地与资源循环

特殊棋在标准模式中的生命周期为：

`三连有限奖励池 → 棋篮 → 棋盘 → 被淘汰 → 所属阵营墓地 → 四连复活 → 棋盘`

- 三连抽到某种特殊棋时，该类型的剩余奖励数量减 1。
- 特殊棋进入棋盘后不会自动补回三连奖励池。
- 特殊棋被直接吃子、二连或四连淘汰后进入所属阵营墓地。
- 基础棋被淘汰后直接离场。
- 墓地只保存特殊棋，并采用最近阵亡者优先的顺序。
- 四连复活会从墓地取走当前最优先的棋并放回棋盘。
- 灵魂不会死亡，也不会进入墓地。

## 落子争锋完整规则

“落子争锋”保留轮流落子与连线博弈，移除棋盘移动和标准模式的四连选择复活，把特殊棋能力改为一次性的落子攻击，并由四连自动回收墓地棋。

### 1. 回合与操作

- 每个正常回合必须落下一枚当前可用棋子。
- 棋盘上的任何非灵魂棋都不能再次移动。
- 不能主动结束回合。
- 棋篮非空时必须使用栈首特殊棋；棋篮为空时才落基础棋。
- 普通回合超时时，系统会在合法空格自动落下当前必须使用的棋子。

三连获得的特殊棋不会立刻攻击，也不能在产生奖励的同一回合使用。它会进入棋篮尾部，等待对手完成回合，并在下一次己方回合轮到它成为栈首时落下。

### 2. 落子争锋二连：基础棋落子挤压

落子争锋的二连与标准模式不同，必须同时满足：

- 本次行动是从棋篮落下一枚基础棋；
- 该方向完整连续线长度恰好为 2；
- 二连中的两枚棋都是基础棋；
- 该方向至少存在一枚没有普通同伴保护的敌方非灵魂目标。

特殊棋可以连接在三连、四连和五连中，但只要二连包含特殊棋，就不会触发二连淘汰。特殊棋落子也不会触发二连。

目标、保护、边缘和灵魂规则与标准模式二连相同：只检查二连两端紧邻的敌棋；目标正后方的同阵营非灵魂棋可以保护；棋盘边缘视为无保护；灵魂不能被淘汰，也不能保护其他棋。

落子争锋会先基于落子完成后的同一棋盘快照，锁定所有方向的二连目标，再同时删除。先删除一枚棋不会改变另一个方向的保护关系，也不会产生继续吃子的连锁。

### 3. 落子争锋三连：特殊棋入栈

- 每个恰好三连的方向分别抽取一枚特殊棋。
- 同一落子同时形成多条三连时，会获得多枚特殊棋，而不是合并成一枚。
- 奖励按照横向、纵向、左上至右下斜线、右上至左下斜线的固定顺序加入棋篮尾部。
- 棋篮可以储存和积累多枚特殊棋，但使用时必须先进先出。
- 每次抽取都会消耗对应类型的有限供应；库存为 0 的类型不再参加抽取。
- 奖励只进入棋篮，不会在三连生成时立即发动攻击。

### 4. 特殊棋落子攻击

当棋篮栈首是特殊棋时，玩家选择一个空格落下它：

1. 拖动或选择落点时，棋盘完整显示该落点所有可攻击敌棋的标记。
2. 攻击范围使用本页“特殊棋数量与棋子规则”中标明的落子争锋攻击规则计算；未单独调整的棋型沿用其标准移动吃子形状。
3. 目标只包括敌方非灵魂棋；空格、己方棋和灵魂不属于攻击目标。
4. 落下前锁定与预览相同的目标快照。
5. 落下后同时淘汰快照中的所有目标，不会因先吃掉一枚棋而重新计算路线。
6. 特殊棋攻击后留在落点，保持普通非灵魂棋状态。
7. 它可以连接三连、四连和五连，但不能移动、不能触发二连，也不会在五连中飞升。

例如，车落下后会同时攻击四条直线上各自可按车规则吃到的敌棋；炮仍然需要每个方向恰好隔着一个炮架；马仍然受蹩马脚限制；象仍然受象眼限制。皇／后只攻击四条斜线；将／帅沿两条双向延长的“仕线”攻击；士／仕攻击朝向己方将／帅的三向一格目标。

### 5. 落子争锋四连：全局淘汰

- 每个恰好四连的方向先把己方墓地中最近阵亡的一枚特殊棋自动移回棋篮，再获得一次全局淘汰权；墓地为空时仍会获得淘汰权。
- 可以选择场上任意一枚敌方或己方非灵魂棋。
- 可以选择基础棋或特殊棋，但不能选择灵魂。
- 多个方向形成四连时，需要逐次处理每一次淘汰。
- 自动回收不要求玩家选择落点，也不会取代全局淘汰。墓地画面会暂时保留这枚回收棋，直到它真正从棋篮落到棋盘才刷新。
- 若场上已经只剩灵魂，没有任何合法目标，剩余淘汰权自动清除并结束当前回合。

主动淘汰己方棋可能用于拆除阻挡或改变阵形。被淘汰的己方特殊棋同样进入墓地，可由之后的四连自动回收。

### 6. 落子争锋五连及以上

- 五连及以上仍然触发灵魂飞升。
- 只将连线中的基础棋转化为灵魂。
- 特殊棋可以作为连接棋，但保留普通非灵魂状态，不会参与飞升。
- 多方向五连分别结算，交点基础棋只计分一次。
- 五连不会直接结束对局。

### 7. 多方向快照与固定顺序

落子争锋会先基于同一落子后的棋盘状态，分别判定横向、纵向和两条斜线的完整长度，再按照横、纵、左上至右下、右上至左下的顺序表现与结算。

- 一个方向的五连不会压掉另一个方向的二连、三连或四连。
- 二连目标在删除前统一锁定并同时淘汰。
- 每条三连分别抽取奖励并按固定顺序入栈。
- 每条四连分别增加一次待处理的全局淘汰权。
- 同一行动上符合条件的二、三、四、五连效果可以叠加。

### 8. 有限类型库存、墓地与自动回收

每个阵营同时维护三个不同概念：

- **棋篮**：已经通过三连获得、等待按顺序落下的特殊棋；
- **类型供应池**：每种特殊棋还剩多少枚可以被未来三连抽到；
- **墓地**：已经阵亡、等待四连自动回收的特殊棋，最近阵亡者优先。

三连抽中某种棋时，该类型供应减 1。特殊棋无论被二连、特殊棋落子攻击、四连或其他合法方式淘汰，都进入所属阵营墓地，不会自动回到类型供应池。每条四连自动把墓地中最近阵亡的一枚特殊棋移回棋篮，并保留该次全局淘汰。

### 9. 落子争锋终局差异

在落子争锋中，单方只有在基础棋供应为 0 且棋篮中没有当前可取出的特殊棋时，才会因为“棋子耗尽”进入结算。仅剩因将／帅缺席而锁定的士／仕不会让对局无限卡住。

如果最后一枚基础棋形成三连并获得特殊棋，奖励正常入栈，对局继续；该特殊棋将在下一次己方回合使用。棋盘填满、灵魂领先无法追赶、认输和联机断线宽限结束等其他终局条件与标准模式一致。

### 10. 专属 AI 与联机

- 人机对局进入落子争锋后会自动使用针对本模式优化的 AI。
- AI 不会生成移动、复活或主动结束回合等本模式非法行动。
- AI 会评估多方向连线、当前可用特殊棋、墓地自动回收、多目标攻击和四连己方淘汰等规则价值，并对近期重复局面和反复落在同一区域施加惩罚。
- AI 与联机对局都使用同一套王、仕、皇落地攻击和士／仕取出限制；双方都能看到对方的上一步落点提示。
- 在线匹配会把两种规则分开，相同难度但不同规则的玩家不会进入同一房间。

## 特殊棋数量与棋子规则

### 每方特殊棋类型上限

| 棋型 | 蓝方／红方 | 每方上限 |
| --- | --- | ---: |
| 王棋 | 将／帅 | 1 |
| 护卫 | 士／仕 | 2 |
| 象棋 | 象／相 | 2 |
| 车 | 车 | 2 |
| 马 | 马 | 2 |
| 炮 | 炮 | 2 |
| 兵种 | 卒／兵 | 5 |
| 全能棋 | 皇／后 | 1 |

每方共有 17 枚特殊棋的类型容量。两种模式中，抽出的特殊棋死亡后都会进入墓地而不自动返还三连供应；标准模式通过四连选择复活，落子争锋通过四连自动回收最近阵亡棋。

### 通用目标规则

- 除基础棋外，特殊棋在标准模式移动时可以进入敌方非灵魂棋所在格并直接吃子。
- 不能移动到己方棋所在格。
- 灵魂不能成为直接吃子目标。
- 直线棋遇到阻挡后不能继续穿越；炮按照独立的炮架规则处理。
- 落子争锋不允许盘上移动。除将／帅、士／仕、皇／后采用本版单独标明的落地攻击外，其余棋型把下列移动与吃子形状用作落子攻击范围。

### 基础棋

- 标准模式：只能向上、下、左、右移动一格，目标必须为空；不能直接吃子，通过移动二连挤压敌棋。
- 落子争锋：不能移动；落下形成符合条件的二连时立即挤压。

### 将／帅

- 标准模式：可以向横、竖、斜八个方向移动一格，并直接吃掉终点的敌方非灵魂棋。
- 落子争锋：以落点朝己方前进方向一格为两条“仕线”的交点，沿穿过交点的两条完整斜线向四端双向延伸；每个分支遇到第一枚棋即停止。
- 交点本身被占用时会阻断四条分支；若交点或分支首枚棋是敌方非灵魂棋，则会被攻击。
- 被吃不会直接输掉对局；两种模式中都会进入墓地。

### 士／仕：动态九宫

- 标准模式：必须有己方将／帅在场才能行动；九宫以己方将／帅为中心动态形成，士／仕在九宫内斜走，位于九宫外时沿接近将／帅的斜线返回。路线会被棋子阻挡，合法终点可以吃敌方非灵魂棋。
- 落子争锋：己方将／帅不在场时不能从棋篮取出；锁定期间会留在原顺序位置，系统继续寻找后面的当前可用棋。
- 落下时攻击朝向己方将／帅的方向及左右相邻方向，共三个一格目标。

### 象／相

- 固定斜走两格。
- 中间一格是“象眼”，象眼被任何棋占据时该方向不可走。
- 可以吃终点的敌方非灵魂棋。
- 没有传统象棋的过河限制。

### 车

- 沿横向或纵向移动任意距离。
- 遇到第一枚棋时停止；若第一枚阻挡棋是敌方非灵魂棋，可以吃掉它。
- 不能越过任何棋继续移动或攻击。

### 马

- 按“日”字移动。
- 每个日字方向对应一个紧邻的“马脚”。
- 马脚被任何棋占据时，该轴向对应的两个马步都失效。
- 合法终点为空时可以移动，是敌方非灵魂棋时可以吃子。

### 炮

- 不吃子时沿横向或纵向移动，路径上不能有阻挡。
- 吃子时必须在同一条直线上恰好越过一枚棋作为炮架。
- 炮架之后遇到的第一枚棋如果是敌方非灵魂棋，才是合法目标。
- 炮架之后的空格不是合法的普通移动终点；遇到第一枚棋后也不能继续向更远目标攻击。
- 己方棋、敌方棋和灵魂都可以成为炮架。

### 卒／兵

- 可以向己方前方移动一格，也可以向左或向右横移一格，普通移动目标必须为空。
- 只能吃斜前方一格的敌方非灵魂棋。
- 不使用传统象棋的过河前后规则。

### 皇／后

- 标准模式：结合车与斜线长距离移动，可以沿横、竖和四条斜线移动任意距离；遇到第一枚棋时停止并可吃掉敌方非灵魂棋。
- 落子争锋：只沿四条斜线攻击，不包含横线和竖线；每个方向遇到第一枚棋时停止，第一枚棋是敌方非灵魂棋时将其吃掉。

## 灵魂、计分与终局

### 灵魂的全部性质

- 连线中的每枚基础棋飞升后成为 1 枚灵魂，并计 1 分。
- 灵魂永久占据当前格。
- 灵魂不能移动、不能落子攻击，也不能直接吃子。
- 灵魂不能被普通移动吃子、二连挤压、特殊棋落子攻击或四连全局淘汰。
- 灵魂不能参与之后的二、三、四、五连，并会中断普通连线。
- 灵魂不能保护其他棋免受二连挤压。
- 灵魂会阻挡车、皇／后等直线棋，也会堵住象眼和马脚。
- 灵魂可以作为炮架。

灵魂既是最终分数，也是无法清除的永久地形。飞升可能锁定优势，也可能封住己方未来路线。

### 正常终局条件

正式对局会在以下情况结算：

1. **棋子供应耗尽**：标准模式中，任意一方基础棋供应为 0；落子争锋中，任意一方基础棋供应为 0 且棋篮也为空。
2. **棋盘填满**：没有任何空格。
3. **灵魂领先已经无法追赶**：领先方当前灵魂数严格超过落后方根据现有棋盘结构理论上仍可能达到的最大值。
4. **玩家认输**：认输方立即失败。
5. **联机断线宽限结束**：断线方未能在权威恢复期限内返回。

如果仍存在未处理的四连选择权，系统会先完成四连阶段，再进行正常终局比较。

### 终局比较顺序

棋盘填满或棋子供应耗尽时：

1. 比较双方灵魂数量，灵魂较多者获胜；
2. 灵魂相同时，比较棋盘上的普通非灵魂棋数量；
3. 普通棋数量仍相同，则判为平局。

五连只是生成灵魂与分数，不会在没有满足以上条件时直接结束游戏。

## 超时、认输与联机断线

### 普通回合超时

- 倒计时采用绝对时间，不会因为掉帧、切到后台、AI 思考、重连或房主迁移而反复延长。
- 普通回合超时时，系统根据本局确定性随机状态，在合法空格自动放置当前必须使用的棋子。
- 若已经不存在可以落下的棋或合法空格，系统安全结束当前回合或进入正式终局判断。

### 四连阶段超时

- 标准模式优先自动使用可用复活；没有复活候选时，再选择合法敌方棋进行全局淘汰；两者都无法执行时安全完成该次选择。
- 落子争锋没有复活，会优先选择合法淘汰目标；系统通常优先处理敌棋，在没有敌棋时可以处理己方非灵魂棋；没有任何合法目标时清除剩余权利。

### 认输与断线

- 玩家可以认输，认输方立即失败。
- 在线模式不会把瞬时掉线直接判负，而会冻结相关输入并进入断线恢复宽限。
- 只有断线方未在权威宽限结束前恢复时，才以断线超时结束。
- 房主发生迁移时，当前回合、棋盘、库存、墓地、随机状态和四连阶段都由权威快照继续同步。

## 对战方式与教程

### 本地 AI 对战

- 玩家与 AI 使用同一套规则，AI 没有额外棋子、隐藏信息或非法行动权限。
- 简单、中等、困难分别使用不同搜索深度、候选规模和思考预算。
- 落子争锋自动启用针对无移动、多方向连线、特殊棋落子攻击与有限库存优化的专属 AI。

### 本地双人

两名玩家在同一台设备上轮流操作，共用同一棋盘与界面。回合切换时会同步刷新当前阵营、倒计时、棋篮、库存、墓地或新模式对应信息。

### 在线双人

- 两名玩家通过在线匹配进入同一房间。
- 匹配会同时区分规则模式和难度。
- 对局使用权威行动提交、状态版本与哈希校验、完整快照、断线恢复和房主迁移。
- 不同规则版本或不同规则模式的客户端不能混入同一局。

### 教程

教程固定使用 9×9 棋盘和标准模式，包含新手入门、基础棋、各类特殊棋、三连、四连、五连以及完整实战教程。完整实战会在一盘连续棋局中演示落子、移动、直接吃子、二连各种情况、特殊棋奖励、墓地复活、飞升和终局比较。
