# Chess Melee Demo

This repository provides playable demo downloads for **Chess Melee**.
The Unity project and game source code are maintained in a private repository.

## 下载 Demo

可玩版本发布后，请前往 [Releases](https://github.com/TechJoiH/Chess-Melee-Demo/releases) 下载对应平台的压缩包。

当前目录中的游戏构建文件只用于本地打包，不会直接提交到 Git 历史；正式 Demo 将以 Release 附件形式发布。

## 反馈

如遇到问题，请通过本仓库的 Issues 提交反馈，并附上操作系统、复现步骤和截图。
